# Code of Conduct

We welcome respectful participation, regardless of background, identity,
experience or ability. Discuss ideas constructively, help newcomers and respect
people's privacy.

Harassment, discrimination, threats, personal attacks and disclosure of private
information are unacceptable in project issues, pull requests and community spaces.

Report concerns privately to [contact@alien6.com](mailto:contact@alien6.com), with
the subject `HankoShell Academy conduct`. Maintainers handle reports confidentially
and may request corrections, remove content or restrict participation. A maintainer
involved in a report should not decide its outcome. Requests for reconsideration
can use the same contact. Security reports follow [SECURITY.md](SECURITY.md).
