# Security policy

Security fixes target `main`, the source synchronized to Killercoda. Older
scenario revisions and forks do not receive separate backports. The operator and
other public components have their own release and security policies.

Use [GitHub private vulnerability reporting](https://github.com/Alien6-Studio/hankoshell-labs/security/advisories/new).
If unavailable, contact [contact@alien6.com](mailto:contact@alien6.com) to arrange
a private reporting channel. Do not disclose exploitable details in public issues.

Include the scenario, source revision, impact and minimal reproduction with
synthetic data. Never include live tokens, private keys, tenant information or
existing cluster configuration. The labs are disposable learning environments;
do not enter real credentials or connect them to an existing system.

For operator vulnerabilities, follow its [security policy](https://github.com/Alien6-Studio/hankoshell-operator/security/policy).
